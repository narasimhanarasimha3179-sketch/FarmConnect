# 🌾 FarmConnect

FarmConnect is a full-stack agricultural platform designed to empower farmers with direct marketplace access, AI-assisted plant pathology diagnosis, APMC mandi pricing intelligence, and smart farming advisory.

## 📁 Repository Modules
* `mobile-android/`: Native Android application built with React Native & Expo SDK.
* `backend/`: RESTful API server powered by Node.js, Express, and MongoDB.
* `frontend/`: Web dashboard for administrative oversight and bulk commodity trading.

## 📋 Phase 0 Architecture Documents
* `ARCHITECTURE.md`: High-level system architecture and network data flows.
* `TECH_STACK.md`: Complete framework, library, and runtime specifications.
* `DATABASE_DESIGN.md`: MongoDB schema blueprints and entity relational models.
* `API_SPECIFICATION.md`: REST API endpoint definitions and contracts.

* `SECURITY_DESIGN.md`: Data protection, token transport, and sanitization guidelines.
